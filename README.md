# Landing Pages

Набор продающих лендингов для малого бизнеса. Тёмная готовая вёрстка на чистом HTML/CSS, легко адаптируется под конкретный проект.

## Содержимое

- `index.html` — лендинг кофейни «Утро» (пример для бизнеса)
- `assets/` — изображения для лендингов

## Как использовать

1. Скопируйте нужный HTML-файл.
2. Замените текст, контакты и изображения на свои.
3. Разместите на хостинге или Github Pages.

Сделано на чистом HTML/CSS без фреймворков — легко редактируется.
